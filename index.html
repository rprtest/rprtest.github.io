Model Context Protocol (MCP)

How AI models connect to external tools, APIs, and data sources — and why it changes what agents can do.

April 2026

MCP is an open standard that lets AI models like Claude talk to external services — databases, APIs, file systems — through a common interface. Think of it as a USB-C port for AI: any model, any tool, one protocol.
